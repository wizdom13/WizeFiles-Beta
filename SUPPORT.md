# Support and Feedback

This repository supports public beta testing of WizeFiles.

## Where to post

- Use a [bug report](../../issues/new?template=bug_report.yml) for a reproducible defect.
- Use a [storage/provider problem](../../issues/new?template=provider_problem.yml) for local storage, SAF, SD card, USB, cloud, FTP, SFTP, SMB, WebDAV, or S3 problems.
- Use a [feature request](../../issues/new?template=feature_request.yml) for one focused suggestion.
- Use [Discussions](../../discussions) for general feedback, testing experiences, and questions.

Search existing issues before creating a new one. Please keep each issue focused on one problem.

## Not supported here

- Security vulnerability details in public
- Account recovery or credential handling
- Requests for proprietary source code
- Third-party or modified APKs
- Problems that cannot be connected to an official WizeFiles Beta release

For security issues, follow [SECURITY.md](SECURITY.md).

## Response expectations

Beta feedback is reviewed and prioritized, but a response, workaround, fix, or implementation date cannot be guaranteed. Clear reproduction steps and sanitized diagnostics greatly improve the chance of action.
